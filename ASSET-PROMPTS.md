# Debrief asset sources

Generated with the built-in image-generation tool for this game. The shipped WebP files live in `docs/assets/`; they are encoded for offline play. Original generated PNGs remain outside the repository. The existing canvas landscape and color palette are preserved.

The specimen atlas is a 3 × 3 sheet. `docs/art.js` displays only the cell associated with a discovered exhibit. Map paths, labels, landmarks, controls and notebook text remain live accessible markup rather than text baked into artwork.
